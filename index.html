Scriptable setup instructions

Option A — Paste the JSON directly:

  1. Install Scriptable from the App Store.
  2. Create a new script and paste the JSON above into a const data = {...} variable.
  3. Build a ListWidget that loops over data.habits and draws each title, streak, and a checkmark when completedToday is true.
  4. Add the Scriptable widget to your Home Screen and select your script. Re-paste the JSON for fresh data.

Option B — Fetch from a local server:

  1. Serve this folder: python -m http.server 8000
  2. Save the JSON as widget.json in that folder.
  3. In Scriptable: const r = await new Request('http://<your-ip>:8000/widget.json').loadJSON() — phone and computer on the same Wi-Fi.
  4. The widget can then refresh on its own schedule.
